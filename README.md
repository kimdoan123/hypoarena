# 🧪 hypoarena - Discover Hypotheses With Evidence Graphs

[![Download hypoarena](https://img.shields.io/badge/Download-hypoarena-ff69b4?style=for-the-badge&logo=github)](https://github.com/kimdoan123/hypoarena)

hypoarena is a scientific hypothesis-discovery workbench for Windows users who want to explore ideas, connect them to evidence, and compare competing explanations in a clear, repeatable way. It helps you build grounded hypothesis-evidence graphs, work with synthetic literature that contains planted causal chains, and run generate-debate-evolve loops over swappable offline adapters. In plain terms: you can ask the workbench to propose ideas, argue them against one another, improve them over rounds, and rank them, all without needing an internet connection.

The application is designed for normal computers. The main engine uses NumPy, and an optional CPU-only torch extra is available. You do not need a graphics card to use the workbench.

## 🚀 What hypoarena Does

hypoarena turns early-stage scientific thinking into a structured workspace. You can create a project, load practice literature, build a map of ideas and evidence, and let the workbench test which hypotheses hold up best.

A hypothesis-evidence graph is a visual map. Each hypothesis is connected to the evidence that supports or weakens it. This makes it easier to see where an idea is strong, where it is thin, and where more evidence is needed.

Synthetic literature with planted causal chains means the app includes practice documents where cause-and-effect links are deliberately placed. You can use these documents to check whether the workbench finds the connections you expect. This is useful for learning, testing settings, and comparing runs.

Generate-debate-evolve loops are repeated rounds of idea work. The app generates candidate hypotheses, has them debated against one another, and evolves the strongest ones. Over several rounds, weak ideas are filtered out and stronger ideas are refined.

Elo tournaments rank hypotheses through head-to-head comparisons, similar to a tournament. The app can recover a planted skill order, which means it checks whether the final ranking matches the hidden quality order in the practice data. Paraphrase deduplication spots repeated ideas written in different words and removes duplicates. Bayesian evidence accumulation updates confidence as evidence arrives, instead of treating every clue as equally important. Reproducible reports save the settings and results so a report can be regenerated later.

## 🗂️ Understanding the Main Panels

**Hypothesis-Evidence Graph.** This is the center of the workbench. Hypotheses sit as nodes, and evidence sits around them, linked by lines. Thicker or stronger links mean stronger support.

**Synthetic Literature.** This panel holds practice documents. The planted causal chains are built in, so you can test whether the app finds the links you already know exist. Compare the found chains against the planted ones to judge a run.

**Generate-Debate-Evolve Loop.** This panel runs repeated rounds. Generation creates candidate ideas. Debate pits them against each other. Evolution keeps and refines the strongest. You choose how many rounds to run.

**Elo Tournament.** This panel runs head-to-head comparisons and produces a ranking. The planted skill order recovery check tells you whether the final ranking matches the hidden quality order in the practice data.

**Paraphrase Deduplication.** This panel groups ideas that say the same thing in different words and removes the extra copies, so your graph stays clean.

**Bayesian Evidence Accumulation.** This panel updates confidence as evidence is added. New evidence does not simply add up; it shifts belief in a measured way.

**Reproducible Reports.** This panel saves the settings and results together. You can generate the same report again later and compare runs side by side.

## 🔌 Offline Adapters

hypoarena uses pluggable offline adapters to do its idea work. An adapter is a helper that the workbench connects to. Because the adapters are offline, the workbench does not need an internet connection to generate, debate, or evolve hypotheses. You can switch between adapters in the settings area to compare how each one performs on the same project.

The NumPy core handles the main calculations. If you add the CPU-only torch extra, additional adapter options become available. The extra is optional and works on a processor-only computer.
